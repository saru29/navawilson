# CLAUDE.md

Astro static site replacing the WordPress/Elementor site at navawilson.law. Built the same way as prcoach.ca.

- **Read `docs/BUILD_GUIDE.md` first**: progress table, decisions, open questions. Update it after each step.
- The user is new to Astro and comes from Angular: work step by step and explain (compare to Angular where it helps).
- Node 22 (`.nvmrc`). `npm run dev` (http://localhost:4321), `npm run build`, `npm run preview`, `npm run import:wp`.
- Keep the live site's colours (red `#ce2028`, dark grey `#434141`, lavender `#f1f1fa`, white). Small style changes are fine.
- Zero JS where possible (`<details>`, scroll-snap). Plain CSS with variables, no Tailwind.
- Content in `src/content/` was generated by `scripts/import-wordpress.mjs`. Re-running it overwrites hand edits.
- Keep code comments rare: none by default, otherwise one short line.
- Don't push, touch DNS (name.com) or hosting, or change the Cloudways WordPress site without asking. Work on a branch and open a PR.
- Forms carry client data. Don't route sensitive intake (IDs, wills details, uploads) through third-party email services without sign-off.
